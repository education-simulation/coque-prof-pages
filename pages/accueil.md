# Bienvenue

Ceci est la page d'accueil de ton site. Tu peux la modifier : c'est le fichier `pages/accueil.md`.

- Le **menu** à gauche se règle dans `site.config.js`.
- Chaque page de **texte** est un fichier `.md` dans le dossier `pages/`.
- Chaque page **interactive** (simulation, outil de calcul) est un fichier `.html` dans le même dossier.

> Pour te faire aider : dans l'onglet de ton **atelier** (« RASF — Atelier … »), ouvre ton assistant (**Mistral**, **Claude** ou **ChatGPT**) et écris :
> **« Lis AGENTS.md et guide-moi. »**
